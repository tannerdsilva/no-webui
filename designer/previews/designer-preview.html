07

Component Class Reference

Pattern

.block                    /* component */
.block__element           /* child part */
.block--modifier          /* variant / state */
.block__element--modifier /* child variant */

Examples

.button                   /* button block */
.button__label            /* label inside button */
.button--primary          /* primary variant */
.button--lg               /* large size modifier */
.tabs__tab--active        /* active tab */

Rules

  • Blocks are lowercase, no prefix
  • One element level max (__)
  • Modifiers can stack (button button--primary button--lg)
  • No inline style in production components
  • Use var(--token) instead of raw values

Design Tokens — Quick Reference

How to use tokens

/* ✅ Do this */
.my-class {
  color: var(--color-primary);
  padding: var(--spacing-4);
  font-size: var(--text-base);
  border-radius: var(--radius-md);
}

/* ❌ Don't do this */
.my-class {
  color: #3b82f6;
  padding: 16px;
  font-size: 16px;
  border-radius: 6px;
}

Token categories

--color-{name}       /* semantic + scale colors */
--text-{size}        /* font sizes (alias of --font-size-*) */
--font-{family}      /* font families */
--spacing-{n}        /* spacing (alias of --space-*) */
--radius-{size}      /* border radius */
--shadow-{size}      /* elevation */
--transition-{name}  /* motion */
--z-{layer}          /* stacking */
